# LAN air hockey.. Online, not LAN anymore
This is a free, open-source online game. It may be basic, but it's kinda fun to play at school (definintley after I finish my work...)

## How to use:
1. Open the website (duh)
2. Enter a room code - something like __ROOM123__
3. Pick wether to be P1 or P2 (host/join is vestigial)
4. Have Fun
